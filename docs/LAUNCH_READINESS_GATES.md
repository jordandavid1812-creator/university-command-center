## Evidence handling and phase boundaries

Each evidence record needs a release/settings/schema/secret-version reference, date, exact environment/tool versions, case IDs and results (including failures/skips), sanitized artifact links/checksums, reviewer and outstanding actions. Never attach raw dumps, hashes/tokens, credentials, DSNs, student records, identifiable screenshots or unsanitized error traces. A changed release/schema/proxy/provider can invalidate a prior pass; list what was revalidated. Store sensitive operational evidence in an access-controlled location; a PR contains only redacted conclusions.

Phase L is authorized local synthetic engineering **after** the owner approves implementation scope. Phase S is an independently approved private synthetic lab. Phase P is a separate later public/real-student decision, **not a 5A deliverable**. Provider-free tests can start in L without buying services; every claim about a vendor needs actual S evidence. “Blocked” means a named dependency remains open; it never means an implicit waiver.
